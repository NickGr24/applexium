# Applexium.com — полный редизайн (2026-08-08)

## Цель

Полный редизайн applexium.com в духе работ unseen.co (RSPCA Animal Futures,
25residences.com, cosmos.so): технологичный иммерсивный сайт с 3D-сценами,
скролл-сторителлингом и выразительной типографикой. Референсная планка —
сайт-«мир», а не набор секций с фоном.

Принятые решения (подтверждены пользователем):

1. **Стек**: миграция на React/Vite (отменяет ограничение «no bundler» из CLAUDE.md).
2. **Эстетика**: тёмный иммерсивный техно-мир — эволюция текущего бренда, не разрыв.
3. **Охват**: весь сайт за один заход; максимум эффектов на главной и продуктовых,
   остальные страницы — единая дизайн-система с лёгкими эффектами, юридические — минимализм.
4. **Концепция**: гибрид — «живой мир» в хиро + редакционные главы ниже.

## Технологическая база

- **Vite + React 19**, маршрутизация React Router, **пререндер всех маршрутов
  в статический HTML** (`vite-react-ssg`) — GitHub Pages отдаёт готовые страницы,
  SEO не деградирует.
- **three.js + @react-three/fiber + @react-three/drei** — 3D-сцены. Существующие
  ogl-сцены (`scene.js` аркада, `scene-convergence.js` Emmi) портируются на R3F.
- **GSAP + ScrollTrigger + Lenis** — скролл-анимации и инерционный скролл.
- **React Bits** — компоненты копируются в репо как исходники (их модель
  распространения), адаптируются под дизайн-систему.
- **Деплой**: GitHub Actions → build → GitHub Pages. Пуш в `main` публикует сайт.
- **Шрифты самохостятся** (woff2 в репо), `font-display: swap`.

### Что уходит / что остаётся

Уходит: `build-en.py`, `data-en`-атрибуты, `en-meta.json`, генерируемая папка `en/`,
монолит `style.css`, AOS, i18n.js, liquid-ether.js.

Остаётся:
- RO-первичность и URL-схема: `/` (румынский) + `/en/*` (английский);
- reciprocal hreflang (`ro`/`en`/`x-default`) + канонические URL на каждой странице;
- JSON-LD (Organization, WebSite, SoftwareApplication, Person, ContactPage,
  BreadcrumbList) с `inLanguage`, локализованный на обе версии;
- `docs/*.docx` — источник правды юридических страниц;
- embed виджета Emmi (`app.emmi-agent.com/widget.js` + agent UUID) без изменений;
- политика cache-bust `?v=` для widget.js.

### i18n

Словари `ro.json` / `en.json`; каждый маршрут существует в двух вариантах
(`/emmi` и `/en/emmi`), пререндерится со своим `<html lang>`, meta, OG и hreflang.
`sitemap.xml` генерируется на сборке, обе языковые версии, `projects` по-прежнему
исключён (осиротевший плейсхолдер). Переключатель языка — ссылки между URL, без JS-состояния.

### Совместимость URL

Старые URL вида `emmi.html` продолжают работать: пререндерим оба пути
(`/emmi.html` и `/emmi`); canonical у обоих указывает на новый чистый URL.
Клиентский 404-редирект не используем (мигание и слабее для SEO).

## Дизайн-система

### Типографика

| Роль | Шрифт | Использование |
| --- | --- | --- |
| Display | Clash Display (Fontshare) | Заголовки, hero до `clamp(3rem, 10vw, 9rem)`, вес 500–600 |
| Текст | General Sans (fallback Inter) | Параграфы, UI |
| Моно | JetBrains Mono | Номера секций (`01 / SERVICII`), лейблы, статистика, технические подписи |

Моно-слой микротипографики — ключевой «инженерный» приём (как у cosmos.so).

### Палитра

Эволюция бренда: база `#04060D` (глубже текущего `#071116`), брендовый градиент
света `#1C1890 → #245EFE → #1FCDFF` (свет сцен, свечения, акценты), текст `#EDEDF2`.
Продуктовые палитры (Emmi/Legalia/Precedentia) сохраняются как подтона в тёмной базе.
Поверх всего сайта — зерно (grain overlay), склеивающее 3D и HTML.

### Язык движения (глобальный)

- Lenis — инерционный скролл.
- Переходы между страницами — маска-шторка с лого-символом (React Router + GSAP).
- SplitText-реверлы заголовков (строки из-под маски); ScrambledText/DecryptedText
  для моно-лейблов.
- Магнитные кнопки/ссылки; кастомный курсор (точка → кольцо на интерактивных).
- `prefers-reduced-motion` отключает всё движение.

### Карта эффектов (порты React Bits / codrops-техники)

| Место | Эффект |
| --- | --- |
| Сервисы | MagicBento / SpotlightCard — спотлайт за курсором |
| Портфолио | ChromaGrid / GridDistortion — шейдер-искажение изображений на ховер |
| Команда | ImageTrail / шейдер-ховер фото |
| Статистика | CountUp + моно-цифры |
| Фоны продуктов | Emmi — конвергенция потоков; Legalia — beams/лучи; Precedentia — частицы-галактика |

## Страницы

### Главная (максимум эффектов)

1. **Хиро-мир** — R3F-эволюция «аркады в воде»: арки, отражения, объёмный свет,
   частицы; параллакс камеры за курсором; при скролле камера въезжает в аркаду,
   заголовок расслаивается — переход в первую главу без разрыва.
2. **Манифест** — одно крупное высказывание, слова проявляются по скроллу.
3. **Продукты** — три полноэкранные витрины со скролл-пином: фоновый шейдер
   продукта, крупное имя, 2–3 факта моно, CTA на продуктовую страницу.
4. **Сервисы** — bento-сетка со спотлайтом.
5. **Портфолио** — лента с шейдер-искажением на ховер.
6. **Цифры + клиенты** — CountUp.
7. **CTA-финал** — крупная типографика, магнитная кнопка, фон закольцовывает мир хиро.

### Продуктовые страницы (единый шаблон)

Своя мини-сцена в хиро (развитие шейдера с главной), затем редакционные главы:
возможности → каналы/фичи → тарифы/факты → CTA. Emmi сохраняет живой виджет и обе
CTA-кнопки (скролл к `#voiceagent-widget-root`, pulse FAB, фолбэк на контакты).
Актуальные данные продуктов брать по памяти `product-data-sources`
(локальные репо + Supabase, а не устаревшие README).

### Остальные

- **Команда** — сетка фото с шейдер-ховером; профили — редакционный шаблон.
- **Портфолио-страница, контакты** — общая система, лёгкие эффекты; форма с
  микросостояниями.
- **Юридические (6)** — чистая типографика, оглавление, без WebGL; синхронизация
  с `docs/*.docx` сохраняется.

## Перфоманс и фолбэки

- Уровни графики: детект слабых устройств (DPR, `hardwareConcurrency`,
  `prefers-reduced-motion`) → сцены деградируют до статичного кадра с зерном;
  на мобильных — упрощённые сцены (меньше частиц, без постпроцессинга).
- 3D-сцены — ленивые чанки (code-splitting); хиро-LCP ≤ 2.5s; шрифты swap.
- Мобильная планка прежняя: каждая страница презентабельна на iPhone-классе.

## Критерии успеха

1. Сайт ощущается «одним пространством»: переходы, зерно, единый свет.
2. Lighthouse mobile: Performance ≥ 70 на главной (с учётом 3D), ≥ 90 на юридических.
3. SEO-паритет: обе языковые версии в статике, hreflang/JSON-LD/sitemap не хуже текущих.
4. Виджет Emmi работает как сейчас.
5. Контент редактируется без пересборки сцен (тексты в словарях/компонентах).
